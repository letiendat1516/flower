# 💐 Bó hoa 20/10 tặng em

Trang web tĩnh: một bó hoa rực rỡ, nở dần, có thả tim và lá thư nhỏ để chúc mừng ngày Phụ nữ Việt Nam 20/10.

## Đổi tên và lời nhắn

Mở `assets/js/main.js`, sửa object `CONFIG` ở đầu file:

- `recipient`: tên người nhận (mặc định "Em yêu")
- `sender`: tên người gửi, ký cuối thư (mặc định "Anh")
- `wish`: lời chúc ngắn dưới bó hoa
- `letterTitle`, `letter`, `signOff`: tiêu đề, nội dung và lời ký của lá thư

## Xem thử

Mở `index.html` bằng trình duyệt (bấm đúp vào file).

## Bật GitHub Pages

Vào **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
Khoảng 1 phút sau trang sẽ có ở `https://<username>.github.io/<tên-repo>/`.
